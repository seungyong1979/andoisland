# 여수 안도 사운드트랙

## 열기
`index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 사이트입니다.
로컬 서버를 이용하려면 이 폴더에서 `python3 -m http.server 8765` 실행 후 http://localhost:8765 를 엽니다.

## 기능
수채화 섬의 지점 선택, 4가지 소리 믹싱, 개별/전체 음량, 재생/일시정지, 반복 재생, 5·15·30·60분 종료 타이머, 브라우저 내 조합 저장/복원, 모바일 레이아웃.
타이머는 설정 순간부터 경과 시간을 기준으로 하며 일시정지 중에도 시간이 흐릅니다. 백그라운드 브라우저의 절전 정책에 따라 실행 시점이 지연될 수 있습니다.

## 실제 음원 연결
현재 음원은 Web Audio로 만든 체험용 합성음이며 안도 현장 녹음이 아닙니다.
1. 사용 권한이 있는 안도 현장 녹음을 `audio/`에 넣습니다.
2. `sounds.js`에서 각 항목의 빈 `src`를 `audio/waves.mp3` 같은 상대 경로로 변경합니다.
3. `name`, `english`, `title`은 원하는 녹음명으로 수정합니다.
4. 연결한 항목에는 실제 음원이 반복 재생되고, 미연결 항목에는 합성음이 유지됩니다.
외부 서버 음원보다 같은 폴더의 파일을 권장합니다. 자동 재생은 하지 않으며 최초 재생 버튼 클릭이 필요합니다.

## 파일
- index.html: 페이지 구조 및 소개 문구
- style.css: 반응형 스타일
- app.js: 플레이어/믹서/저장 기능
- sounds.js: 소리 이름과 실제 음원 경로
- img/ando-watercolor.png: 생성한 수채화 섬 일러스트
- IMAGE-PROMPT.txt: 이미지 생성 방식과 프롬프트

일러스트는 안도에서 영감을 받은 상상 풍경이며 정확한 지도가 아닙니다. 참고 사이트의 소리 파일이나 로고는 복제하지 않았습니다.
요청하신 폴더에 로컬 파일로 저장하는 작업이며 웹 배포는 하지 않았습니다.
기존 img 참고 사진은 그대로 보존했습니다.
