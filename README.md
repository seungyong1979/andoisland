# 여수 안도 사운드트랙

index.html을 브라우저에서 여세요. 별도 설치나 빌드가 필요 없습니다.

## 음원 넣기
아래 파일명으로 audio 폴더에 MP3 파일을 넣으면 연결됩니다.
- 01-waves.mp3
- 02-forest.mp3
- 03-wind.mp3
- 04-village.mp3
- 05-island.mp3

제목과 경로, 트랙 개수는 sounds.js에서 수정합니다. 파일이 없을 때는 '아직 음원이 준비되지 않았습니다.'가 표시됩니다. 합성음은 사용하지 않습니다.

## 구성
전체 사진 배경 + 플레이리스트. 재생/일시정지, 이전/다음, 재생 위치 이동, 한 곡 반복, 음소거, 음량 조절. 한 곡이 끝나면 다음 곡으로 이동합니다. 마지막 곡 다음은 첫 곡입니다.
사진은 제공된 img 폴더의 안도 해안 사진을 img/ando-bay.png로 복사해 사용합니다. 기존 참고 사진과 이전 수채화 자산은 보존했습니다.
하단 소개, 설명, 믹서, 타이머, 조합 저장 기능은 제거했습니다.

테스트용 로컬 서버: python3 -m http.server 8765
접속: http://localhost:8765
