# 여수 안도 사운드트랙

index.html을 브라우저에서 열면 됩니다. 사진 배경, 빈티지 카세트, 플레이어와 플레이리스트로 구성됩니다.

## 음원
- audio/01.mp3: 안도로 들어가는 배 안의 소리
- audio/02.mp3: 안도의 잔잔한 파도 소리
- audio/03.mp3: 안도 몽돌해수욕장
- audio/04.mp3: 갈매기 떼의 소리
- audio/05.mp3: 안도 풀벌레 소리
제목과 간단한 설명은 sounds.js에서 수정합니다. 사용자 제공 MP3 원본을 그대로 사용합니다.

## 재생
재생/일시정지, 이전/다음, 재생 위치 이동, 한 곡 반복, 음소거와 음량 조절을 지원합니다. 카세트 라벨은 현재 곡 제목으로 바뀝니다. 실제 재생 중에만 두 릴이 회전하고, 일시정지·버퍼링·종료 시에는 멈춥니다. 운영체제의 동작 줄이기 설정에서는 회전 애니메이션을 생략합니다.

로컬 서버가 필요하면 이 폴더에서 python3 -m http.server 8765 실행 후 http://localhost:8765 를 엽니다.
